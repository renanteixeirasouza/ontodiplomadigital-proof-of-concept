# Gráficos e imagens extraídos da dissertação

Esta pasta reúne imagens incorporadas ao arquivo canônico da dissertação `dissertacao0209.docx`, extraídas para fins de consulta, rastreabilidade e apoio à leitura dos artefatos da OntoDiplomaDigital.

As imagens foram preservadas como arquivos independentes para facilitar a inspeção dos modelos conceituais, diagramas, trechos técnicos, representações visuais e evidências gráficas citadas no texto da dissertação.

## Organização

- `imagens_extraidas_docx/`: imagens extraídas diretamente do documento Word.
- `manifesto_imagens_extraidas.csv`: relação técnica das imagens, com nome original no DOCX, nome publicado, formato, dimensões e tamanho.
- `preview_imagens_extraidas.jpg`: prancha visual com miniaturas para navegação rápida.

## Observações de uso

A nomenclatura dos arquivos segue a ordem técnica de extração do DOCX e não substitui a numeração formal das figuras na dissertação. Caso a numeração das figuras seja alterada no texto final, o índice desta pasta deve ser usado apenas como apoio de identificação visual.

As imagens foram incluídas como complemento documental do repositório e não caracterizam publicação independente da dissertação.
