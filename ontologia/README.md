# Ontologia

Esta pasta contém os arquivos Turtle principais da prova de conceito.

| Arquivo | Função |
|---|---|
| `OntoDiplomaDigital_registro_diploma.ttl` | TBox da ontologia, com classes, propriedades, restrições, vocabulários controlados e documentação. |
| `ontologia_operacional_individuos_ficticios_registro_diploma_publico.ttl` | ABox pública com instâncias fictícias usadas na demonstração operacional. |

A TBox define a estrutura formal da ontologia. A ABox representa exemplos fictícios de diplomas, diplomados, cursos, instituições, registros, assinaturas e códigos de validação.
