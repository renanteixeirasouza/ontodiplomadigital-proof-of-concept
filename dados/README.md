# Dados tabulares

Esta pasta contém arquivos CSV utilizados como apoio à prova de conceito.

| Arquivo | Função |
|---|---|
| `dados_diplomas_pratica_mapeamento_publico.csv` | Fonte tabular pública usada como base de demonstração do mapeamento. |
| `ontologia_operacional_individuos_ficticios_registro_diploma_amigavel_publico.csv` | Versão tabular simplificada para inspeção humana. |
| `ontologia_operacional_individuos_ficticios_registro_diploma_wide_publico.csv` | Versão tabular ampliada, com mais campos por linha. |
| `tabela_individuos_registro_diploma_publico.csv` | Relação de indivíduos representados na ABox pública. |

Todos os arquivos usam dados fictícios ou sanitizados.
